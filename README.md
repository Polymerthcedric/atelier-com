# Atélier

A static website concept for a fictional furniture-restoration and interiors studio. The page uses only HTML and CSS; there is no JavaScript and no build step.

The studio, projects, prices, dates, statistics, and contact address on the page are sample content. The page labels them as samples so it cannot be mistaken for a real business.

## View it locally

Open `index.html` in a browser. Concept footer items are intentionally not linked.
